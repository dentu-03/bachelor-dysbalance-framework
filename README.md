# Bachelorarbeit: AI-Based Multimodal Dysbalance Framework

Dieses Repository enthält die technische Grundlage meiner Bachelorarbeit.

## Arbeitstitel

Towards a Generalizable AI-Based Multimodal Dysbalance Framework:  
Explainable Modeling, Anomaly Detection and Longitudinal Tracking of Personalized Physiological Deviations

## Ziel

Ziel ist die Entwicklung eines KI-basierten, multimodalen und erklärbaren Dysbalance-Frameworks zur Erkennung, Erklärung und longitudinalen Verfolgung personalisierter physiologischer Abweichungen.

Das Projekt baut auf dem KI-Studienprojekt "Explainable Multisensor Health Model" auf, wird jedoch als eigenständige Bachelorarbeits-Codebasis weitergeführt.

## Geplante Pipeline

Rohdaten  
→ Parser  
→ Synchronisation  
→ Windowing  
→ Tensorisierung  
→ KI-Zeitreihenanalyse  
→ Dysbalance-Scores  
→ Anomalieerkennung  
→ Longitudinal Dysbalance Memory  
→ GUI-Demonstrator

## Wissenschaftlicher Kern

Der Fokus liegt nicht auf einer App oder einzelnen Sensoren, sondern auf einem KI-basierten Framework zur Analyse multimodaler Biosignale.

Kernkomponenten:

- Parser und Datenharmonisierung
- Tensorisierung von Biosignal-Zeitreihen
- MultiRocket / Zeitreihen-KI
- personalisierte Referenzmodellierung
- erklärbare Dysbalance-Scores
- Anomalieerkennung
- longitudinale Musterverfolgung
- GUI-Demonstrator zur Visualisierung
